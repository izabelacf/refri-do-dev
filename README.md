# 🥤 Refri Dev

Projeto desenvolvido para praticar **HTML, CSS e JavaScript**, com foco em estilização, animações e interação entre elementos da página.

A interface permite navegar entre diferentes sabores de refrigerante utilizando botões laterais.

## Tecnologias

- HTML
- CSS
- JavaScript

## Funcionalidades

- Navegação entre os sabores
- Alteração dinâmica dos elementos da página
- Animações com CSS
- Uso de variáveis CSS para alterar as cores de fundo

## Créditos

Projeto desenvolvido para fins de estudo com auxílio de um vídeo do **DevClub** no YouTube.
